# browser-router Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `browser-router` binary that is the default browser, routes each link to a Firefox profile by rules, records the hosts it opened, and offers a fuzzel picker to assign hosts to profiles.

**Architecture:** One Rust binary with small pure modules (`url`, `rules`, `recent`, `profiles`) that are unit tested, and three thin IO modules (`store`, `launch`, `picker`) tested by hand. Data lives in two tab-separated text files under `~/.local/share/browser-router/`, read fully on each run and written by temp-file-and-rename. Desktop integration is one `.desktop` entry, one zsh completion file, one `install.sh` link pair, and one Hyprland bind.

**Tech Stack:** Rust 1.97 stable via mise, cargo. Crates: `clap` 4 (derive), `url` 2, `libc` 0.2. Dev: `tempfile` 3. fuzzel 1.14 for the picker. Firefox from Fedora's `/usr/bin/firefox`.

**Spec:** `docs/superpowers/specs/2026-10-07-browser-router-design.md`

## Global Constraints

- Binary installs to `~/.local/bin/browser-router` with `cargo install --path browser-router --root ~/.local`.
- Data directory: `$XDG_DATA_HOME/browser-router`, fallback `~/.local/share/browser-router`.
- `rules` lines: `pattern<TAB>profile`. `recent` lines: `host<TAB>unix-seconds`. `#` and blank lines are ignored.
- Recent list cap: 200 lines, newest first, one line per host.
- Default profile when no rule matches: the `*` rule, else `Personal`.
- Longest matching pattern wins. A host pattern matches the host and every subdomain.
- `rule <profile> <pattern>`: profile first, pattern last. No `add` word.
- Launch is one spawn with `setsid`, stdio at `/dev/null`, no wait.
- The graphical session PATH is only `/usr/local/bin:/usr/bin`. Desktop Exec and the Hyprland bind use the absolute path `/home/robertherbst/.local/bin/browser-router`.
- Commit messages never mention Claude Code. Every commit ends with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Commit messages, comments, and docs follow Simplified Technical English: short sentences, active voice, answer first.
- One deviation from the spec, decided here: the zsh completion is a hand-written file `browser-router/_browser-router`, not generated by clap. Clap's static generator cannot complete profile names or recent hosts. The file calls `browser-router profiles`, `browser-router recent --hosts`, and `browser-router rules --patterns` for values. Task 7 updates the spec.

## Review Focus

1. A host pattern like `github.com` must also match `gist.github.com` but must not match `notgithub.com`. Pinned in Task 2.
2. A prefix pattern `github.com/ticketsolve/` must not match `github.com/ticketsolve-fork/`. Pinned in Task 2.
3. A `rule` whose pattern is a full URL, pasted from the clipboard, must become `host/path` and not be stored with the scheme. Pinned in Task 7.
4. A `mailto:` or other host-less URI handed to `open` must go to the default profile and must not be recorded. Pinned in Task 1 and Task 7.
5. A rules or recent file with CRLF endings or trailing spaces, after a hand edit, must still parse. Pinned in Task 2 and Task 3.

impl Rules {
    pub fn parse(text: &str) -> Rules {
        let mut out = Rules::default();
        for raw in text.lines() {
            let line = raw.trim();
            if line.is_empty() || line.starts_with('#') {
                continue;
            }
            let Some((pattern, profile)) = line.split_once('\t') else { continue };
            let (pattern, profile) = (pattern.trim(), profile.trim());
            if pattern.is_empty() || profile.is_empty() {
                continue;
            }
            out.set(pattern, profile);
        }
        out
    }

    pub fn to_text(&self) -> String {
        let mut s = String::new();
        if let Some(d) = &self.default {
            s.push_str(&format!("*\t{d}\n"));
        }
        for r in &self.rules {
            s.push_str(&format!("{}\t{}\n", r.pattern, r.profile));
        }
        s
    }

    pub fn default_profile(&self) -> &str {
        self.default.as_deref().unwrap_or(FALLBACK_PROFILE)
    }

    pub fn matched(&self, target: &Target) -> Option<&Rule> {
        self.rules
            .iter()
            .filter(|r| pattern_matches(&r.pattern, target))
            .max_by_key(|r| r.pattern.len())
    }

    pub fn profile_for(&self, target: &Target) -> String {
        match self.matched(target) {
            Some(r) => r.profile.clone(),
            None => self.default_profile().to_string(),
        }
    }

    pub fn set(&mut self, pattern: &str, profile: &str) {
        if pattern == "*" {
            self.default = Some(profile.to_string());
            return;
        }
        let pattern = pattern.to_ascii_lowercase();
        match self.rules.iter_mut().find(|r| r.pattern == pattern) {
            Some(r) => r.profile = profile.to_string(),
            None => self.rules.push(Rule { pattern, profile: profile.to_string() }),
        }
    }

    pub fn remove(&mut self, pattern: &str) -> bool {
        if pattern == "*" {
            return self.default.take().is_some();
        }
        let pattern = pattern.to_ascii_lowercase();
        let before = self.rules.len();
        self.rules.retain(|r| r.pattern != pattern);
        self.rules.len() != before
    }
}

fn host_matches(pattern_host: &str, host: &str) -> bool {
    host == pattern_host
        || (host.len() > pattern_host.len()
            && host.ends_with(pattern_host)
            && host.as_bytes()[host.len() - pattern_host.len() - 1] == b'.')
}

fn pattern_matches(pattern: &str, target: &Target) -> bool {
    match pattern.split_once('/') {
        None => host_matches(pattern, &target.host),
        Some((h, p)) => host_matches(h, &target.host) && target.path.starts_with(&format!("/{p}")),
    }
}

impl Recent {
    pub fn parse(text: &str) -> Recent {
        let mut entries: Vec<Entry> = text
            .lines()
            .filter_map(|raw| {
                let line = raw.trim();
                if line.is_empty() || line.starts_with('#') {
                    return None;
                }
                let (host, seen) = line.split_once('\t')?;
                let seen = seen.trim().parse::<u64>().ok()?;
                let host = host.trim();
                if host.is_empty() {
                    return None;
                }
                Some(Entry { host: host.to_string(), seen })
            })
            .collect();
        entries.sort_by(|a, b| b.seen.cmp(&a.seen));
        Recent { entries }
    }

    pub fn to_text(&self) -> String {
        self.entries
            .iter()
            .map(|e| format!("{}\t{}\n", e.host, e.seen))
            .collect()
    }

    pub fn record(&mut self, host: &str, now: u64) {
        self.entries.retain(|e| e.host != host);
        self.entries.insert(0, Entry { host: host.to_string(), seen: now });
        self.entries.truncate(CAP);
    }
}

//! Start Firefox for a profile and let go of it.
//!
//! One spawn. The child calls setsid so it owns its session and process
//! group, and its stdio points at /dev/null. The router does not wait.
//! When the router exits the kernel reparents Firefox to the user's
//! subreaper. Firefox's own remote protocol hands the URL to a running
//! instance of that profile, or starts one.

use std::io;
use std::os::unix::process::CommandExt;
use std::process::{Command, Stdio};

pub fn firefox(profile: &str, url: &str) -> io::Result<()> {
    let mut cmd = Command::new("firefox");
    cmd.arg("-P")
        .arg(profile)
        .arg(url)
        .stdin(Stdio::null())
        .stdout(Stdio::null())
        .stderr(Stdio::null());
    // SAFETY: setsid is async-signal-safe and touches no Rust state.
    unsafe {
        cmd.pre_exec(|| {
            if libc::setsid() == -1 {
                return Err(io::Error::last_os_error());
            }
            Ok(())
        });
    }
    cmd.spawn().map(|_| ())
}

pub fn pattern_from(input: &str) -> String {
    let input = input.trim();
    if input.contains("://") {
        if let Some(t) = url::normalise(input) {
            return t.key();
        }
    }
    input.to_ascii_lowercase()
}

fn load_rules() -> Rules {
    Rules::parse(&store::read(&store::rules_path()))
}

fn load_recent() -> Recent {
    Recent::parse(&store::read(&store::recent_path()))
}

fn save_rules(r: &Rules) -> Result<(), String> {
    store::write_atomic(&store::rules_path(), &r.to_text()).map_err(|e| format!("cannot write rules: {e}"))
}

fn save_recent(r: &Recent) -> Result<(), String> {
    store::write_atomic(&store::recent_path(), &r.to_text()).map_err(|e| format!("cannot write recent: {e}"))
}

fn cmd_open(raw: &str) -> Result<(), String> {
    let rules = load_rules();
    let Some(target) = url::normalise(raw) else {
        return launch::firefox(rules.default_profile(), raw).map_err(|e| format!("cannot start firefox: {e}"));
    };
    let profile = rules.profile_for(&target);
    let mut recent = load_recent();
    recent.record(&target.host, store::now());
    if let Err(e) = save_recent(&recent) {
        eprintln!("browser-router: {e}");
    }
    launch::firefox(&profile, raw).map_err(|e| format!("cannot start firefox: {e}"))
}

fn cmd_rule(profile: &str, pattern: &str) -> Result<(), String> {
    let known = profiles::load();
    if !known.iter().any(|p| p == profile) {
        return Err(format!("unknown profile {profile:?}; known: {}", known.join(", ")));
    }
    let mut rules = load_rules();
    rules.set(&pattern_from(pattern), profile);
    save_rules(&rules)
}

fn cmd_rules(patterns_only: bool) {
    let rules = load_rules();
    if patterns_only {
        for r in &rules.rules {
            println!("{}", r.pattern);
        }
        return;
    }
    print!("{}", rules.to_text());
}

fn cmd_unrule(pattern: &str) -> Result<(), String> {
    let mut rules = load_rules();
    if !rules.remove(&pattern_from(pattern)) {
        return Err(format!("no rule for {pattern:?}"));
    }
    save_rules(&rules)
}

fn cmd_recent(hosts_only: bool) {
    let rules = load_rules();
    for host in load_recent().hosts() {
        if hosts_only {
            println!("{host}");
        } else {
            let t = url::Target { host: host.to_string(), path: "/".to_string() };
            println!("{host}\t{}", rules.profile_for(&t));
        }
    }
}

fn cmd_profiles() {
    for p in profiles::load() {
        println!("{p}");
    }
}

fn run(cli: Cli) -> Result<(), String> {
    match cli.cmd {
        Cmd::Open { url } => cmd_open(&url),
        Cmd::Rule { profile: None, pattern: None } => {
            cmd_rules(false);
            Ok(())
        }
        Cmd::Rule { profile: Some(p), pattern: Some(pat) } => cmd_rule(&p, &pat),
        Cmd::Rule { .. } => Err("usage: browser-router rule <profile> <pattern>".into()),
        Cmd::Rules { patterns } => {
            cmd_rules(patterns);
            Ok(())
        }
        Cmd::Unrule { pattern } => cmd_unrule(&pattern),
        Cmd::Recent { hosts } => {
            cmd_recent(hosts);
            Ok(())
        }
        Cmd::Profiles => {
            cmd_profiles();
            Ok(())
        }
    }
}

fn main() -> ExitCode {
    match run(Cli::parse()) {
        Ok(()) => ExitCode::SUCCESS,
        Err(e) => {
            eprintln!("browser-router: {e}");
            ExitCode::FAILURE
        }
    }
}
